16-float - Posicionamiento Flotante

El posicionamiento flotante se utiliza para colocar una caja a la izquierda o derecha, permitiendo que el texto fluya a su alrededor.

Demostración Interactiva de Float

Selecciona el valor de float para la caja roja y aplica clear al párrafo para ver cómo interactúan.

Este es un párrafo con un fondo gris. Si aplicas clear, este párrafo dejará de rodear la caja flotante y bajará hasta que la caja termine.

/* Ejemplo de Float */
.imagen { float: left; } /* La imagen flota a la izquierda y el texto la rodea */

/* Ejemplo de Clear */
.parrafo { clear: both; } /* El párrafo baja y no rodea la imagen */
