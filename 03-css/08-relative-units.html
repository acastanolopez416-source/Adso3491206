08-relative-units

Especifique una longitud relativa a otra propiedad de longitud.

  • pixel (px)
  • m (em)
  • x (ex)
  • root M (rem)
  • viewport units horizontal (vh)
  • viewport units width (vw)
  • large viewport (lvh|dvw)
  • small viewport (svh|svw)
  • dynamic viewport (dvh|dvw)

Example

  • px: 15 px
  • em: 1.5 em
  • rem: 2rem
  • ex: 2.4ex
