01-emmet

Plugin para codificación más rápida en HTML y CSS.

01-CHILD>
Crea elementos hijos (anidación)

ejemplo

ul>li>a ♏

resultado:

<ul> <li> <a href="">Link</a> </li> </ul>

sibling

02-sibling>
Crea elementos hermanos

ejemplo

section+menu+div♏

resultado:

<section></section> <menu></menu> <div></div>

multiplicacion

03-multiplicacion>
repite elementos varias veces

ejemplo

ul>li*3♏

resultado:

<ul> <li></li> <li></li> <li></li> </ul>

class

03-class>
crea un atributo de clase

ejemplo

menu.main♏

.container♏

resultado:

<menu class="main"></menu> <div class="container"></div>

classes

03-classes>
Crea múltiples atributos de clase.

ejemplo

menu,main.upper.blue♏

resultado:

<menu class="main upper blue"></menu>
