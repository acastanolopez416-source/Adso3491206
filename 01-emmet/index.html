01-EMMET

Plugin para codificación más rápida en HTML y CSS.

01-Child >
Crea elementos hijos (anidación).

Ejemplo:

ul>li>a ↔️

Resultado:

<ul> <li> <a href=""></a> </li> </ul>

02-sibling: +
Crea elementos hermanos.

Ejemplo:

section+menu+div ↔️

Resultado:

<section></section> <menu></menu> <div></div>

03-Multiplication: *
Repite elementos varias veces.

Ejemplo:

ul>li*5 ↔️

Resultado:

<ul> <li></li> <li></li> <li></li> <li></li> <li></li> </ul>

04-Class: .
Crea un atributo de clase.

Ejemplo:

menu.main
.container ↔️

Resultado:

<menu class="main"></menu> <div class="main"></div>

05-Classes: ...
Crea múltiples atributos de clase.

Ejemplo:

menu.main.upper.blue ↔️

Resultado:

<menu class="main upper blue"></menu>

06-Identifition: #
Crea un atributo de ID.

Ejemplo:

nav#menu ↔️

Resultado:

<nav id="menu"></nav>

07-Text:{}
Inserta contenido de texto.

Ejemplo:

div{Lorem Ipsum Dolor}
a{Click Aquí}↔️

Resultado:

<div>Lorem Ipsum Dolor</div> <a href="">Click Aquí</a>

08-Custom Attribute: []
Crea atributos personalizados.

Ejemplo:

a[href=www.google.com] ↔️

Resultado:

<a href="www.google.com"></a>

09-Item Numbering: $
Añade números consecutivos.

Ejemplo:

ul>li.num$*3
section>article.sec$$$*3 ↔️

Resultado:

<ul> <li class="num1"></li> <li class="num2"></li> <li class="num3"></li> </ul> <section> <article class="sec001"></article> <article class="sec002"></article> <article class="sec003"></article> </section>

10-Reverse Numbering: @-
Invierte el orden de numeración.

Ejemplo:

ul>li.num$@-*3 ↔️

Resultado:

<ul> <li class="num3"></li> <li class="num2"></li> <li class="num1"></li> </ul>

11-Base Numbering: @n
Define un número base para secuencias.

Ejemplo:

ul>li.num$@3*4 ↔️

Resultado:

<ul> <li class="num3"></li> <li class="num4"></li> <li class="num5"></li> <li class="num6"></li> </ul>

12-Climb Up: ^
Sube un nivel.

Ejemplo:

section>article>div^p ↔️

Resultado:

<section> <article> <div></div> </article> <p></p> </section>

13-Grouping: ()
Agrupa elementos juntos.

Ejemplo:

(header>nav)(section>article) ↔️

Resultado:

<header> <nav></nav> </header> <section> <article></article> </section>

15-HTML Documents: html:
Crea varios tipos de documentos HTML.

Ejemplo:

html: ↔️

Resultado:

html:5 --> un index

16-Meta Tags: meta:
Genera etiquetas meta.

Ejemplo:

meta: ↔️

Resultado:

<meta http-equiv="X-UA-Compatible" content="IE=7">

header#heder>nav.navbatinverse>div.container>(div.navbar-header>(button.navbar-toggle[type=button]>span.sr-only{toggleNavegation}+span.incon-bar*3)+a.nav-brand[heref=index.php]>img[src=imgs/logo.png])(div.collapse>(ul.nav_navbar-nav>(li>a.link[href=index.html]{inicio})+(li.active_link>a[href=loging.html]{ingresar})+(li>a.link[href=registro.html]{registrarse})+(li>a.link[href=contacto.html]{contacto})))
